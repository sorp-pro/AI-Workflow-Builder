description: Войти в разбор процессов — завести ключ или назваться готовым
---

Опознать участника и, если он захочет, включить запись обращений.

## Если человек назвал имя и код

```bash
node "${CLAUDE_PLUGIN_ROOT}/bin/vhod.mjs" "<имя>" <код>
```

Скажи, кем он вошёл. **Отдельно и обязательно** передай то, что напечатает
команда про запись обращений: плагин может писать его вопросы в общий журнал,
и включается это отдельным действием.

Не уговаривай включать. Человек ставил плагин, чтобы разбирать процессы, а не
чтобы отдавать переписку; решение его, и оно ничего не ломает.

## Если у него уже есть ключ

```bash
node "${CLAUDE_PLUGIN_ROOT}/bin/vhod.mjs" --ключ <ключ>
```

## Если ничего не назвал

Посмотри, не вошёл ли он:

```bash
node "${CLAUDE_PLUGIN_ROOT}/bin/vhod.mjs"
```

Вошёл — назови имя, роль и состояние записи. Не вошёл — попроси имя и код
приглашения **одной строкой**, без объяснений про устройство хранилища.

## Согласие

```bash
node "${CLAUDE_PLUGIN_ROOT}/bin/vhod.mjs" --согласие
node "${CLAUDE_PLUGIN_ROOT}/bin/vhod.mjs" --отозвать
```

Отозвать можно в любой момент. Записанное раньше остаётся на стенде — об этом
скажи честно, если спросят.

## Выход

```bash
node "${CLAUDE_PLUGIN_ROOT}/bin/vhod.mjs" --выйти
```

Забывает ключ на этой машине. Участник и его прошлые обращения в журнале
остаются: журнал, из которого можно вычистить свои следы, ничего не стоит.
