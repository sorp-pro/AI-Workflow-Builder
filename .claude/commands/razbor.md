---
description: Разбор процессов — пройти по местам, где реестр не заполнен
---

Веди человека по местам, где в реестре чего-то не хватает, и записывай его
решения на стенд. Вопросы приходят со стенда, файл ни от кого получать не надо.

## Сначала — где ты запущен

Этой команде нужна папка плагина со скриптами. Проверь:

```bash
test -f "$CLAUDE_PROJECT_DIR/sorp-svod/scripts/razbor.mjs" && echo есть || echo нет
```

**Нет** — значит, ты в чате claude.ai или в другой среде, куда плагин приходит
одними инструкциями, без скриптов и без хуков. Не ищи скрипт по машине и не
изображай вход или разбор своими силами: ключ, участника и запись заводит
только скрипт на стенде. Скажи человеку одной строкой:

> Разбор процессов работает во вкладке **Code** приложения Claude. Откройте её
> и напишите там /sorp-svod:vhod.

И больше ничего не делай.

**Есть** — продолжай.

## Начни с обзора

```bash
node "$CLAUDE_PROJECT_DIR/sorp-svod/scripts/razbor.mjs"
```

Скажи человеку одной строкой, сколько мест закрыто и сколько осталось. Не
пересказывай разбивку по основаниям — она понадобится ниже, при каждом
вопросе.

## Бери вопросы небольшими пачками

```bash
node "$CLAUDE_PROJECT_DIR/sorp-svod/scripts/razbor.mjs" --вопросы 5
```

Пачками, а не всё сразу: мест нехватки больше тысячи, и человек, увидевший
тысячу вопросов, не ответит ни на один.

## Как задавать

По одному месту за раз, и каждый раз называй **основание** — на чём стоит
предложенное:

| Основание | Что это значит для отвечающего |
|---|---|
| `из реестра` | так уже записано в другом месте реестра |
| `из правила` | выведено из правила устройства процессов |
| `по аналогии` | так устроены соседние шаги того же процесса |
| `догадка` | не выведено ниоткуда, поставлено, чтобы было что оспорить |

**Догадку называй догадкой прямо.** Помеченная догадка видна и оспорима,
непомеченная — тихо становится правдой реестра.

Спрашивай кнопками через AskUserQuestion: варианты — предложенное, «не то» и
«не знаю». Уклончивый ответ ответом не считается: «наверное, как обычно»
оставь незакрытым и скажи об этом прямо.

## Записывай решения сразу

```bash
node "$CLAUDE_PROJECT_DIR/sorp-svod/scripts/razbor.mjs" --да 101387000000112977
node "$CLAUDE_PROJECT_DIR/sorp-svod/scripts/razbor.mjs" --нет 101387000000112977 "стол другой, ведёт DESK-012"
```

Сразу, а не в конце: сессия обрывается, и час разговора пропадает целиком.

Отклонение без причины команда не примет — и правильно: на следующем прогоне
движок предложит ровно то же самое, потому что не узнает, чем оно было плохо.

## Чего не делать

Не отвечай за человека. Если он не знает — так и оставь: незакрытое место
видно и когда-нибудь закроется, а закрытое наугад не видно никогда.
