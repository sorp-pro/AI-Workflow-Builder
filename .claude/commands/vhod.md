---
description: Войти в разбор процессов — имя и ключ плагин заведёт сам
---

Опознать участника. Его вопросы и выбор в вопросах с кнопками пишутся в журнал разбора с момента входа.

## Сначала — где ты запущен

Этой команде нужна папка плагина со скриптами. Проверь:

```bash
test -f "$CLAUDE_PROJECT_DIR/sorp-svod/scripts/vhod.mjs" && echo есть || echo нет
```

**Нет** — значит, ты в чате claude.ai или в другой среде, куда плагин приходит
одними инструкциями, без скриптов и без хуков. Не ищи скрипт по машине и не
изображай вход или разбор своими силами: ключ, участника и запись заводит
только скрипт на стенде. Скажи человеку одной строкой:

> Разбор процессов работает во вкладке **Code** приложения Claude. Откройте её
> и напишите там /sorp-svod:vhod.

И больше ничего не делай.

**Есть** — продолжай.

## Если человек ничего не назвал

Это обычный случай — просто выполни:

```bash
node "$CLAUDE_PROJECT_DIR/sorp-svod/scripts/vhod.mjs"
```

Уже вошёл — команда назовёт имя, роль и состояние записи. Передай это.

Не вошёл — команда скажет «Вы не вошли» и **ничего не заведёт**. Тогда спроси
одной строкой: «Как вас зовут? Если у вас уже есть ключ — пришлите его.»

- Ответит **именем** — делать ничего не надо: хук поймает его реплику и сам
  заведёт участника и ключ.
- Пришлёт **ключ** (`sorp_…`) — войди им, см. ниже. Так входит человек,
  который уже заведён на другом компьютере: второй раз назваться тем же
  именем стенд не даст.

Под названным именем вопросы человека будут видны всем, кто читает журнал, и
подменить его потом нельзя — только завести второго участника.

Стенд может быть закрыт или спрашивать код приглашения — тогда хук или
команда так и скажут. Передай их слова и, если нужен код,
попроси его **одной строкой**: выдаёт тот, кто ведёт стенд.

## Если он назвал имя, или имя и код

```bash
node "$CLAUDE_PROJECT_DIR/sorp-svod/scripts/vhod.mjs" "<имя>"
node "$CLAUDE_PROJECT_DIR/sorp-svod/scripts/vhod.mjs" "<имя>" <код>
```

Скажи, кем он вошёл. **Отдельно и обязательно** передай то, что напечатает
команда про запись: его вопросы Claude и выбор в вопросах с кнопками пишутся
в общий журнал разбора под его именем. Одной строкой, без извинений.

## Если у него уже есть ключ

```bash
node "$CLAUDE_PROJECT_DIR/sorp-svod/scripts/vhod.mjs" --ключ <ключ>
```

## Запись

Идёт всегда, выключателя нет: разбор ведётся для своих, и журнал нужен целым.
Если спросят, как выключить, — так и скажи.

## Выход

```bash
node "$CLAUDE_PROJECT_DIR/sorp-svod/scripts/vhod.mjs" --выйти
```

Забывает ключ на этой машине. Участник и его прошлые обращения в журнале
остаются: журнал, из которого можно вычистить свои следы, ничего не стоит.

После выхода плагин снова не пропускает вопросы — это то же состояние, что и
сразу после установки. Если человеку нужно работать без входа, скажи ему про
`SORP_SKIP_LOGIN=1` в окружении, а не предлагай снять плагин.
