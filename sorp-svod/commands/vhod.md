description: Войти в разбор процессов — имя и ключ плагин заведёт сам
---

Опознать участника и, если он захочет, включить запись обращений.

## Сначала — где ты запущен

Этой команде нужна папка плагина со скриптами. Проверь:

```bash
test -f "${CLAUDE_PLUGIN_ROOT}/scripts/vhod.mjs" && echo есть || echo нет
```

**Нет** — значит, ты в чате claude.ai или в другой среде, куда плагин приходит
одними инструкциями, без скриптов и без хуков. Не ищи скрипт по машине и не
изображай вход или разбор своими силами: ключ, участника и запись заводит
только скрипт на стенде. Скажи человеку одной строкой:

> Разбор процессов работает во вкладке **Code** приложения Claude. Откройте её
> и напишите там /sorp-svod:vhod.

И больше ничего не делай.

**Есть** — продолжай.

## Если человек ничего не назвал

Это обычный случай — просто выполни:

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/vhod.mjs"
```

Команда сама разберётся, что делать. Не вошёл — возьмёт имя из `git config
user.name` и заведёт ключ. Уже вошёл — назовёт имя, роль и состояние записи.

Имя она печатает вместе с тем, откуда взяла. **Передай это человеку дословно**:
под этим именем его вопросы будут видны всем, кто читает журнал, и подменить
его потом нельзя — только завести второго участника, разорвав след пополам.

Обычно этого достаточно. Но стенд может быть закрыт или спрашивать код
приглашения — тогда команда так и скажет. Передай её слова и, если нужен код,
попроси его **одной строкой**: выдаёт тот, кто ведёт стенд.

## Если он назвал имя, или имя и код

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/vhod.mjs" "<имя>"
node "${CLAUDE_PLUGIN_ROOT}/scripts/vhod.mjs" "<имя>" <код>
```

Скажи, кем он вошёл. **Отдельно и обязательно** передай то, что напечатает
команда про запись обращений: плагин может писать его вопросы в общий журнал,
и включается это отдельным действием.

Не уговаривай включать. Человек ставил плагин, чтобы разбирать процессы, а не
чтобы отдавать переписку; решение его, и оно ничего не ломает.

## Если у него уже есть ключ

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/vhod.mjs" --ключ <ключ>
```

## Согласие

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/vhod.mjs" --согласие
node "${CLAUDE_PLUGIN_ROOT}/scripts/vhod.mjs" --отозвать
```

Отозвать можно в любой момент. Записанное раньше остаётся на стенде — об этом
скажи честно, если спросят.

## Выход

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/vhod.mjs" --выйти
```

Забывает ключ на этой машине. Участник и его прошлые обращения в журнале
остаются: журнал, из которого можно вычистить свои следы, ничего не стоит.

После выхода плагин снова не пропускает вопросы — это то же состояние, что и
сразу после установки. Если человеку нужно работать без входа, скажи ему про
`SORP_SKIP_LOGIN=1` в окружении, а не предлагай снять плагин.
